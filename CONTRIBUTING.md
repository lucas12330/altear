# Contribuer à Altear

Merci de ton intérêt ! Les contributions (code, correctifs, documentation, traductions, images) sont
bienvenues. Chaque contributeur est **crédité** dans [`CONTRIBUTEURS.md`](CONTRIBUTEURS.md) et dans
l'historique git.

Altear est publié en double licence (AGPL-3.0 pour le code, CC BY-SA 4.0 pour les contenus, + licence commerciale ; voir [`LICENCES.md`](LICENCES.md)).
Pour que cela reste possible, chaque contribution est soumise à l'**accord de contribution** ci-dessous.

   œuvres qui en dérivent.
3. **Contrepartie.** Ta contribution, une fois acceptée, est publiée dans le dépôt public sous la licence
   libre du projet (AGPL-3.0-only pour le code, CC BY-SA 4.0 pour les textes et images), et tu es crédité.
4. **Garanties.** Tu déclares que :
   - la contribution est ton œuvre originale, ou que tu as le droit de la proposer sous ces conditions ;
   - elle ne contient pas de code ou de contenu soumis à une licence incompatible (indique toute partie
     reprise d'ailleurs, avec sa source et sa licence) ;

   - si tu as utilisé un outil d'intelligence artificielle pour la produire, tu le signales.
5. **Mineurs.** Si tu as moins de 18 ans, ton représentant légal doit donner son accord.
6. **Droit applicable.** Cet accord est soumis au droit français.

### Comment l'accepter

- Ajoute à chacun de tes commits la ligne `Signed-off-by: Prénom Nom <e-mail>` (`git commit -s`).
- Écris dans ta demande de fusion : « J'accepte l'accord de contribution Altear v1.0 ».

## Bonnes pratiques

- Une demande de fusion par sujet, avec une description claire.
- Aucun secret (mot de passe, jeton, clé) ni donnée personnelle dans les fichiers.
- Garde les mentions de licence et de copyright existantes.
- Pour un problème de sécurité, écris d'abord en privé à contact@altear.tech au lieu d'ouvrir un ticket public.
